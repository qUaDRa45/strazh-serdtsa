# Страж сердца

Учебная игра по дисциплине «Разработка интерфейсов». Игрок управляет щитом (клавиши W, A, S, D) и защищает сердце от снарядов, скорость которых растёт. Таблица рекордов общая для всех игроков и хранится на сервере.

## Запуск

1. Установите Node.js (подойдёт и портативная версия).
2. В папке проекта выполните:

```
npm install
npm start
```

3. Откройте в браузере http://localhost:3000

Сервер сам раздаёт файлы игры и хранит рекорды в `data/scores.json` (создаётся при первом запуске).
Чтобы в таблице сразу были тестовые результаты, скопируйте `data/scores.example.json` в `data/scores.json`.

`npm test` проверяет логику таблицы рекордов.

## Структура

| Файл | Назначение |
|---|---|
| `server.js` | сервер Express: `GET` и `POST /api/scores`, раздача `public/` |
| `scores.js` | проверка данных и вставка результата в таблицу |
| `test.js` | тесты `scores.js` |
| `public/index.html` | разметка окна игры и всех экранов |
| `public/style.css` | оформление |
| `public/game.js` | игровой движок (canvas) |
| `public/main.js` | меню, экраны, клавиатура, настройки, рекорды |
| `public/api.js` | запросы к серверу |
| `public/sound.js` | звук и музыка |

## API

| Метод | Адрес | Тело | Ответ |
|---|---|---|---|
| GET | `/api/scores` | нет | 200, массив записей |
| POST | `/api/scores` | `{name, score, time}` | 201 и обновлённая таблица (200, если не попал в десятку; 400 при ошибке данных; 500 при сбое сервера) |
